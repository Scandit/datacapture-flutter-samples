# Barcode Selection Settings Sample

This sample demonstrates how to configure and customize barcode selection with various settings to optimize the scanning experience for your specific use case.

## Prerequisites

Before proceeding, you will need a valid Scandit DataCapture SDK license key.
You can retrieve it by signing into your account at https://ssl.scandit.com.

## Installation

Install dependencies:

```bash
flutter pub get
```

Replace the license key in the sample where you see `-- ENTER YOUR SCANDIT LICENSE KEY HERE --`.

## How to run

```bash
flutter run
```
