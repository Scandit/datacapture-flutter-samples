# Matrix Scan AR Simple Sample

This sample demonstrates the MatrixScan AR (BarcodeAR) pre-built component. It shows how to scan multiple barcodes simultaneously and display configurable AR overlays on each detected code.

MatrixScan AR is a pre-built component available via the Barcode AR API of the Scandit Data Capture SDK with fully-customizable AR features for visually tracking and annotating multiple barcodes in real time.

## Installation

- Clone this repo locally.
- Sign in to your Developer Account at [ssl.scandit.com](http://ssl.scandit.com) and generate a license key. If you do not have an account, sign up here: [https://ssl.scandit.com/dashboard/sign-up?p=test](https://ssl.scandit.com/dashboard/sign-up?p=test).
- Replace the license key in the sample where you see `-- ENTER YOUR SCANDIT LICENSE KEY HERE --`.
- Build and run this sample on your mobile device.

## What is MatrixScan AR?

MatrixScan AR extends multi-code scanning with augmented reality overlays, allowing you to display customizable AR elements and metadata directly over detected barcodes in the camera view for enhanced user feedback and data visualization.
