# Search and Find Sample

This sample demonstrates the pre-built MatrixScan Find component (Barcode Find API) for efficiently searching through and finding specific barcodes in a batch.

## Prerequisites

Before proceeding, you will need a valid Scandit DataCapture SDK license key.
You can retrieve it by signing into your account at https://ssl.scandit.com.

## Installation

Install dependencies:

```bash
flutter pub get
```

Replace the license key in the sample where you see `-- ENTER YOUR SCANDIT LICENSE KEY HERE --`.

## How to run

```bash
flutter run
```
