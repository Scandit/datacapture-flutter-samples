# Label Capture Simple Sample

This sample demonstrates the functionality of the Smart Label Capture (LabelCapture) API. It shows how to simultaneously capture data from multiple barcodes and text that appear together on product labels.

## Installation

- Clone this repo locally.
- Sign in to your Developer Account at [ssl.scandit.com](http://ssl.scandit.com) and generate a license key. If you do not have an account, sign up here: [https://ssl.scandit.com/dashboard/sign-up?p=test](https://ssl.scandit.com/dashboard/sign-up?p=test).
- Open the sample project and update the license key in the code (typically in `main.dart` or the data capture initialization file) with your license key.
- Run `flutter pub get` to fetch dependencies.
- Build and run this sample on your mobile device using `flutter run`.

## What is LabelCapture?

LabelCapture is an API of the Scandit Data Capture SDK that coordinates the process of simultaneously capturing data contained in multiple barcodes and text that occur together.
